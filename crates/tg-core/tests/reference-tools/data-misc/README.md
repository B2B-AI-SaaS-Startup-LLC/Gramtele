The constructor/audio classification/AutoDownload Should overloads that dereference
real model objects, service state and complete Session owners are **own tests +
reading**, not native class replay. `probe_owners.py` attempts all five actual full
translation units, with real original stdafx.h and Qt include directories; it does
not stub absent UI/app types. The final probe reaches the missing real generated `emoji.h` from ui/emoji_config.h; no generated UI asset or class is stubbed. The actual result is recorded in the handoff.
TopPeers peer payloads still require the real storage/serialize_peer adapter:
its test codec validates framing/rollback only and is not a production format.
Sender tests use a real Instance/Sender, feed synthetic typed responses at the
callback boundary, and open no sockets. They are not native MTProto server replay.

Out-of-domain C++ signed overflow/NaN casts, QString lone surrogates, cross-language
raw-pointer sort order and arbitrary destructor-time aliasing are not asserted.
